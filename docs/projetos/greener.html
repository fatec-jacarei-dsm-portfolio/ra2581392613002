GREEN COMPUTING DESIGN & DEVELOPMENT — 2026

O PROJETO

GreenER é uma plataforma de monitoramento e análise do impacto ambiental de serviços computacionais, desenvolvida durante o segundo semestre do curso de Desenvolvimento de Software Multiplataforma da FATEC Jacareí.

O DESAFIO

Transformar métricas de infraestrutura em indicadores ambientais acessíveis, permitindo compreender o consumo energético e as emissões de carbono associados aos serviços monitorados.

MINHA CONTRIBUIÇÃO

Atuei no desenvolvimento front-end, na construção da identidade visual e na experiência do usuário, explorando diferentes formas de representar dados complexos por meio de interfaces interativas, visualizações e ferramentas de análise.

TECNOLOGIAS

React TypeScript Node.js PostgreSQL Docker Vite Git
